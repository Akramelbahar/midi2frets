🎸 Guitar Tab Transformer

A PyTorch Transformer that reads Songsterr JSON and predicts the optimal guitar string for every note. Fret is derived deterministically: fret = pitch - tuning[string] - capo.

PyTorch Transformer Encoder Constraint Masking Beam Search Songsterr JSON

What It Does

  • Reads symbolic guitar music from Songsterr JSON files.
  • Predicts only the string (0–5) for each note.
  • Computes fret deterministically from pitch, tuning and capo.
  • Includes a hand-position playability loss and a DP baseline.
  • Supports different capos and tunings in the same training batch.

Architecture

Input features (integers, PAD=0)
  ├── pitch           (0–127)
  ├── duration_bucket (0–9)
  ├── delta_bucket    (0–9)
  ├── beat_position   (0–15)
  ├── bar_position    (0–3)
  ├── chord_size      (0–5)
  └── chord_index     (0–5)

↓ one nn.Embedding per feature, sum → 256-d
↓ sinusoidal positional encoding + dropout
↓ 4-layer Pre-LN Transformer encoder (8 heads, ff=1024)
↓ Dropout + Linear(256, 6)
↓ constraint mask: impossible strings → -inf
↓ softmax → predicted string

Quick Start

1. Install dependencies

pip install -r requirements.txt

2. Validate a Songsterr file

PYTHONPATH=src python src/parser.py data/raw/file.json

Must pass the 100% pitch equation check: pitch == tuning[string] + fret + capo.

3. Train on one song (overfit sanity check)

PYTHONPATH=src python src/train.py \
  --data data/raw/file.json \
  --overfit --no-augment \
  --batch 4 --epochs 200 \
  --save checkpoints/model_noaug.pt

Expected: string accuracy > 95%, typically reaches 100%.

4. Train on multiple songs

PYTHONPATH=src python src/train.py \
  --data "data/raw/file.json" \
         "data/raw/nirvana_smells_like_teen_spirit - Kurt_Cobain___1969_Fender_Mustang___Main_Guitar.json" \
         "data/raw/nirvana_smells_like_teen_spirit - Kurt_Cobain___1969_Fender_Mustang___Overdubs.json" \
  --batch 16 --epochs 50 \
  --save checkpoints/model_multi.pt

5. Evaluate & render ASCII tabs

PYTHONPATH=src python src/evaluate.py \
  --data data/raw/file.json \
  --checkpoint checkpoints/model_multi.pt \
  --render --out data/processed/eval.txt

6. Run DP baseline alone

PYTHONPATH=src python src/dp_baseline.py data/raw/file.json

Adding More Training Data

Songsterr track JSONs are served from a CDN with a per-revision access hash. The hash is only available in your browser's network log.

  1. Discover song/revision IDs:
PYTHONPATH=src python src/fetch_songsterr.py --search "artist song" --out data/processed
  1. Open the tab in a browser, load all tracks, and save the network log as HAR.
  2. Extract track JSONs:
PYTHONPATH=src python src/extract_har.py www.songsterr.com.har --out data/raw
  1. Re-run train.py with the new files.

Key Design Decisions

  • String-only prediction: fret is deterministic, simplifying the output space and guaranteeing physical feasibility.
  • Constraint masking: impossible strings are never sampled at training or inference.
  • Pre-LN Transformer: more stable training than Post-LN.
  • Bidirectional attention: the full sequence is known, so causal masking is unnecessary.
  • Differentiable playability: expected fret via softmax, no argmax.
  • Per-note capo/tuning: enables mixed-dataset training.
